# Loyalty-MobileApp — React Native & Mobile Client Application

A cross-platform mobile loyalty application built with **React Native (Expo)**, **TypeScript**, and **Expo Router**. This application features a decoupled architecture that integrates seamlessly with a custom **WordPress REST API** backend to manage user rewards, authentication, and dynamic content delivery across iOS and Android platforms.

---

## ⚡ Key Architecture & Features

- **Cross-Platform Mobile:** Native performance and responsive UI layouts tailored for both **iOS** and **Android**.
- **Headless WordPress Integration:** Custom REST API fetching and payload processing connecting mobile clients to custom WordPress endpoints.
- **Modern Navigation:** File-based routing structured using **Expo Router** (`/app` directory).
- **Type Safety:** Strict **TypeScript** interfaces for API models, custom hooks, navigation params, and UI components.
- **Modular Component Library:** Scalable UI component architecture designed for high reusability and fast render performance.

---

| Category | Technology |
